# devops_init
Create and initialise Devops and its related infrastructure

Prerequisites : 

OS : Any Linux distro like RHEL , Rocky Linux , Debian 
CPU/RAM/Storage : 4/4 GB/20 GB HDD

Steps to build the infrastructure

1. Switch to root user (make sure where you are running the script the path should have minimum of 5 GB or more)
1. Download the script file init_setup_v1.sh
2. Execute the script file using command : bash init_setup_v1.sh
